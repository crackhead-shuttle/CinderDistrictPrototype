# Setup and run

## Install dependencies

```bash
npm install
```

## Start the dev server

```bash
npm run dev -- --host
```

## Build for production

```bash
npm run build
npm run preview -- --host
```

## Browser controls

- WASD: Move
- Shift: Sprint
- Space: Jump
- E: Enter or exit vehicle
- Escape: Pause menu
- Mouse: Camera orbit
- N: Cycle quality preset

## Notes

This project is intentionally tuned for browser performance and compact gameplay rather than a full production open-world scale.
