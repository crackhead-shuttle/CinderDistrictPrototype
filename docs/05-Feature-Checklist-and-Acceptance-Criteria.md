# Asset import and configuration

## Required assets

- Main character mesh with basic idle and locomotion animation set
- Vehicle mesh with wheel setup and simple material hierarchy
- Modular road sections and sidewalks
- Building shell assets for storefronts and residential blocks
- Street lighting props
- Flag assets or signage placeholders for city flavor

## Material setup

Use physically based material settings for:

- asphalt
- concrete
- painted metal
- window glass
- vegetation
- wet road effect

## Lighting workflow

- Build daytime and sunset lighting setups.
- Create a night scene with emissive windows and stronger contrast.
- Add fog and post-process settings carefully to maintain readability.
- Use lightmaps where appropriate and avoid over-lighting.

## Audio setup

- Footstep SFX set for character movement
- Engine loop for vehicle idle and acceleration
- Traffic ambience loop for the district
- UI click sounds and pause menu transitions

## Quality settings

- Low: mobile-friendly preset
- Medium: default console target
- High: desktop target quality
- Cinematic: high-end visual quality
